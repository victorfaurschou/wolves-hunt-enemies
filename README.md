# Wolves Hunt Enemies

**Enables wolves to proactively attack nearby hostile mobs.**

## 📖 Features

* Wolves automatically attack nearby hostile mobs without the player having to engage them first. 
* The types of mobs this applies to can be configured (default: skeleton, zombie, spider).
* Configurable attack radius, chase distance, and spread behavior (whether wolves distribute across multiple enemies).
* Allow wolves to pick up items and experience dropped by enemies.

## 📋 Usage

Open the config screen via **Mod Menu** or by running `/wolves-hunt-enemies config` in chat.
